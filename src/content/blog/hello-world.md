Welcome! This site is built with [Astro](https://astro.build) and hosted for
free on GitHub Pages. You are reading a Markdown file in `src/content/blog/`.

## Where things live

- Blog posts (like this one) are Markdown files in `src/content/blog/`.
- Papers are listed in `src/data/publications.yaml`.
- Your name and links live in `src/site.ts`.
- The header, footer, and styling live once in `src/layouts/BaseLayout.astro`.

## How to publish

Write a new `.md` file, `git push`, and GitHub Actions rebuilds and deploys
the site. The post's URL is just the file name.

Delete this sample and write your own — happy blogging!
